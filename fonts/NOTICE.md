# Font attribution

The Blackhearth Games studio site uses three free / open-source typefaces.

| Font | Where it's used | Source | License |
|---|---|---|---|
| **Monaspace Neon** (Variable, weight 200–800 + oblique) | terminal — prompt, output buffer, panes, command echo | self-hosted (`fonts/MonaspaceNeon-Var.woff2`) | [SIL Open Font License 1.1](https://scripts.sil.org/OFL) |
| **Monaspace Krypton** (Variable, weight 200–800 + oblique) | UI — window chrome, identity strip, legend, footer | self-hosted (`fonts/MonaspaceKrypton-Var.woff2`) | [SIL Open Font License 1.1](https://scripts.sil.org/OFL) |
| **Press Start 2P** | the `BLACKHEARTH GAMES` wordmark only | self-hosted (`fonts/PressStart2P-Regular.woff2`, latin subset from Google Fonts) | [SIL Open Font License 1.1](https://scripts.sil.org/OFL) |

All three are royalty-free for commercial and non-commercial use. The site has no third-party font CDN dependencies; everything ships from the repo.

- Monaspace Neon and Monaspace Krypton are part of [GitHub Next's Monaspace](https://monaspace.githubnext.com/) superfamily. Shipped as variable webfonts (single file per family covers all weights and the oblique axis). Released under the SIL OFL.
- Press Start 2P is © 2012 Cody "CodeMan38" Boisclair, released under the SIL OFL.
